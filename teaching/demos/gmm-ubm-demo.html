02 / 多人特征汇成一张背景地图

EM 交替做两件事：
分配责任，再移动分布。

E 步：每帧对每个分量分一点“票”。
M 步：按这些软票数更新参数。

背景帧 × 三个高斯分量

默认颜色是分量的软职责混色。切换来源颜色只改变显示，EM 没有读入这些身份。坐标始终固定，椭圆为 1σ / 2σ。

先把一个点看懂，再汇总所有点

这帧，不是硬塞给某一个高斯。

γₜ(k) = wₖ 𝒩(xₜ; μₖ, Σₖ) / Σⱼ wⱼ 𝒩(xₜ; μⱼ, Σⱼ)
nₖ = Σₜ γₜ(k)
μₖ ← Σₜ γₜ(k)xₜ / nₖ
E 步不移动模型；M 步更新权重、均值和方差。不是把每个点交给最近的中心，也不是先按说话人分组训练。
背景帧的平均对数似然对当前模型实际计算；越高，越能解释这份背景数据。

后续注册和打分使用这个快照。继续预览 EM 不会悄悄改掉已采用的 UBM；再次点击“采用”才会替换。

越要借助 UBM 的经验。

同一套分量，变成个人版地图。绿虚线 UBM；橙实线 S 模型。
U：UBM 均值S：MAP 后均值注册经验均值

蓝灰小点是已纳入的注册帧，更浅的点尚未纳入。连线表示从 UBM 到 MAP 的真实参数移动，橙圈标出右侧正在检查的分量。不是整体平移，也不是把所有分量拉向一个“说话人中心”。

看一个分量的“信任比例”。
αₖ = nₖ / (nₖ + r)
μ̂ₖ = (1 − αₖ) μₖᵁᴮᴹ + αₖ Eₖ[x]
nₖ 是该分量的有效软计数，不是注册总帧数 N。不同分量被注册数据覆盖的程度不同，所以 αₖ 不同。没有数据时保持 UBM；r 不是学习率，也不是验证阈值。
用“覆盖单一声学区域”做一次实验。

看被覆盖的分量与几乎没被覆盖的分量，各自移动多少；再把 r 从 16 拉到 0 和 64。r 大时更保守，r = 0 时有数据的分量直接采用注册经验均值，但这不等于更能泛化。未覆盖不一定得到精确零职责，高斯尾部仍可能贡献极小的软计数。

04 / 模型不再改变，只让新语音通过

不像“背景”那么普通，
才算支持目标说话人。

一段测试语音，两份模型同时解释。
比较整段似然，而不是寻找状态路径。

前缀累计 LLR · Σℓₜ
前缀平均 LLR · Σℓₜ / T
判断依据：平均 LLR ≥ τ

同一个测试点，放进两张地图。已纳入的点变深，当前点为橙色。

这里只改变所用的测试前缀，模型参数不变。测试场景的生成身份只用于课堂核对，不输入评分公式。

先各自求混合密度，再取对数作差。

ℓₜ = log p(xₜ | λₛ) − log p(xₜ | λᵁᴮᴹ)
每个 p(x | λ) 都是 Σₖ wₖ𝒩ₖ(x)，不是只取最近 / 最大的一个高斯；更不是先算各分量对数再直接相加。密度不是“身份概率”，LLR 也不是准确率。
每一帧贡献多少，平均分怎样累积？绿柱 / 橙柱：正 / 负单帧证据；深线：前缀平均。

为什么不能只看目标 GMM 的分数？

某帧可能在两个模型下密度都很高，却不特别支持 S。LLR 衡量相对证据。这里用平均 LLR 作演示判定；τ = 0 只是起始设置，不是通用最优阈值，实际系统需用独立开发集、先验与代价校准。

05 / 放回整套说话人系统

共享一张地图，
每个人保留自己的细微差别。

阶段数据与已知信息真正改变什么不能混淆
UBM 训练许多背景人的声学帧，特征汇总。EM 估计共享 GMM 的 w、μ、Σ。高斯分量不是说话人类别；EM 不需要身份标签。
说话人注册目标 S 的注册语音，知道它属于 S。以冻结 UBM 为先验，按分量软统计做 MAP；本页只适配均值。不是用测试语音继续训练，不是无先验地重训 GMM。
验证打分新的待测语音，以及被声明的目标身份 S。不改变模型；计算目标 GMM 与 UBM 的对数似然差。输入声明身份，不输入测试的真实身份；判断仍可能错。
校准与评测独立开发 / 评测试验列表与真实标签。选择阈值、校准分数并统计误接收、误拒绝等。本页模拟场景不是 EER 评测，默认阈值不代表部署设置。

完整的均值自适应公式

γₜ(k) = P(k | xₜ, λᵁᴮᴹ)
nₖ = Σₜ γₜ(k)，Fₖ = Σₜ γₜ(k)xₜ
Eₖ[x] = Fₖ / nₖ
αₖ = nₖ / (nₖ + r)
μ̂ₖ = αₖ Eₖ[x] + (1 − αₖ) μₖᵁᴮᴹ

本页用 UBM 计算一次职责并更新均值；w、Σ 不变。一般框架也可以适配权重和方差，不应把“mean-only”误当成 MAP 的全部定义。零有效计数时保留原分量。

从逐帧到整段

p(xₜ | λ) = Σₖ wₖ𝒩(xₜ; μₖ, Σₖ)
LLR(X) = Σₜ [log p(xₜ | λₛ) − log p(xₜ | λᵁᴮᴹ)]
score(X) = LLR(X) / T

模型采用帧条件独立近似；实际帧可能有相关性。平均分削弱长度尺度影响，不表示时长不影响可靠性。复制同一段数据不产生独立证据，不能用复制来声称判断更可靠。

和 GMM–HMM 语音识别有什么不同？

GMM–HMM 中各声学状态有分布，还要按顺序搜索状态路径。这里一个说话人对应一整套 GMM，用帧分布描述声学特征，不进行单词解码。固定帧集合整体打乱顺序，完整 GMM–UBM 分数不变。

UBM 里的“universal”是不是全世界所有声音？

不是。UBM 来自所选背景人群、语音和信道，代表性仍然有限。背景数据失配会影响系统，不能把一个模型理解成完全正确的“不是此人”分布。

r 越小、自适应越多，是否一定越好？

不一定。短注册语音、声学覆盖不足或噪声可能让经验估计不稳。r 控制数据证据与背景先验的折中，不是优化的学习率，也不是验证阈值。

为什么每位说话人都沿用 UBM 的分量？

自适应保持分量对应关系。覆盖充分的区域可做个人化调整，数据不足的区域保留背景信息；而各自从头训练容易在少量数据上过拟合，分量也不再有自然对应。

后面如何接到 i-vector 或神经网络 embedding？

可以把适配均值按固定分量顺序拼接成 GMM supervector，后续方法再对说话人 / 会话变化建模或学习低维表示。神经网络 embedding 通常直接把整段语音映射成向量，不能把这里的一帧点和上一页的整段 embedding 混成同一个东西。

教学边界、模型约定与参考资料

本页为固定种子的二维模拟特征、三个对角协方差高斯。训练采用实际 EM，M 步方差下限为 0.04；MAP 使用冻结 UBM 的一次软分配和均值更新。打分在对数域使用 log-sum-exp，所有三个分量都参与，不使用 top-N 近似。背景 288 帧、注册最多 160 帧、基础测试段 48 帧，三者分别生成，无真实录音或声纹信息。

权威来源：Reynolds、Quatieri、Dunn：Speaker Verification Using Adapted Gaussian Mixture Models（2000），论文 PDF。本页在原框架下采用 mean-only 的教学简化，不展示声学前端、VAD、信道补偿、分数归一化或真实验证性能。
